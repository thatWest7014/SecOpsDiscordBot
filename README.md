# Demo SecOps Bot
---
### This is provided as a simple demo of a SecOps bot for Discord.
####




---
## SETUP
#### Powershell is the Windows Terminal and Bash is the Linux Terminal
- Install Node.js **AND** NPM from the [Node.js website](https://nodejs.org/download)
- Unzip a download of the GitHub repo and open it in VSCode.
- In a VSC Powershell/Bash Window (`CTRL`+`SHIFT`+`~`) run `npm i` to instaall the pkgs.
- Open `.env` and add in your bot's config data.
- run `npm start` in either the same or a new Powershell/Bash instance.
